# Sakura

Satu lanskap Jepang, tiga cara memandang. Pengalaman web kontemplatif berbasis
React + Vite: jelajahi panorama, ikuti rute pandang, lalu ambil jeda napas 30 detik.

## Jalankan

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Konteks desain

Lihat `PRODUCT.md` dan `DESIGN.md` untuk tujuan produk dan sistem desain.
